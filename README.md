# 📊 NIFTY 50 — Intrinsic Valuation

> **Equity Valuation | FCFE Model | Financial Modelling | Sensitivity Analysis**

A fundamental valuation of the **NIFTY 50 Index** using an FCFE-based approach to estimate its intrinsic value and compare it with the current market level.

---

## 🎯 Project Objective

The objective of this project is to estimate the intrinsic value of the **NIFTY 50 Index** using the **Free Cash Flow to Equity (FCFE) approach**.

The analysis focuses on:

* 📈 Intrinsic value estimation
* 💰 Free Cash Flow to Equity
* 📉 Cost of Equity
* 📊 Historical NIFTY 50 data
* 🎯 Terminal Value
* 🔄 Forecasting
* 📐 Sensitivity Analysis

---

## 🧮 Valuation Approach

### FCFE Valuation

The model estimates the future cash flows available to equity shareholders and discounts them using the cost of equity.

**Core framework:**

```text
Historical NIFTY 50 Data
        ↓
FCFE Calculation
        ↓
Forecast Future FCFE
        ↓
Calculate Cost of Equity
        ↓
Terminal Value
        ↓
Intrinsic Value of NIFTY 50
```
